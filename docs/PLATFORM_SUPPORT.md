# Coding Platform Support

Generated by agentic-bootstrap 0.1.0.

Support is capability-specific. “Enabled” means the adapter was selected; it does not imply that optional credentials, extensions, MCP servers, or models were installed.

| Platform | Selection | Generated/discovered artifacts | Support level |
|---|---|---|---|
| Claude Code | Enabled | CLAUDE.md; .claude/skills; optional .mcp.json | Native |
| OpenAI Codex | Enabled | AGENTS.md; .agents/skills; optional .codex/config.toml | Native |
| Pi Coding Agent | Enabled | AGENTS.md and .agents/skills | Native core; MCP/subagents require extensions |
| OpenCode | Enabled | AGENTS.md; .agents/skills; opencode.json | Native |

## Portable Core

All selected platforms share provider-neutral project instructions, task workflow, ADRs, deterministic validators, and Agent Skills where natively supported. The project-scoped `agentic-bootstrap` skill is advisory: it stops after preview and requires separate human-terminal apply.

## Optional Features

- MCP is generated only when explicitly selected.
- Specialized agents are generated only when explicitly selected.
- Repository-hosting workflows and Git hooks are opt-in.
- Hooks never invoke an LLM or perform bootstrap mutation.
- Pi MCP and subagent parity require separately reviewed extensions; they are not native capabilities.

## Verification

Static adapter contract tests validate syntax and discovery paths. Release smoke tests should record the exact CLI versions and date used for instruction and skill discovery.
